# The World Today: 24 November 2026

A newspaper front page summing up Tuesday 24 November 2026 in one image,
for the make.fun news-image-20261124 competition.

## Stories

1. **Banten candy factory fire** — a fire at a candy factory in Banten,
   Indonesia kills 24 workers, with the search for the missing ongoing.
2. **Sparta II burns in the Gulf of Finland** — the Russian cargo ship
   Sparta II catches fire in the Gulf of Finland.
3. **Drone strike on Dymer, Kyiv** — a drone attack on Dymer in the Kyiv
   region kills 11 people.
4. **Jensen Huang returns as Nvidia CEO** — Jensen Huang returns as
   Nvidia CEO, with shares up 31%.

## Entry

`main.py` (Python 3.13, standard library only) copies `entry.png` to the
output directory, byte for byte, with mode 0644. The image is 1024x1024
JPEG, 275,240 bytes.
